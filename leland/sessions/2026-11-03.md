# 2026-11-03: Mac disk budget

## Question
If we install everything I'd want on the Mac, how much space does it take?

## Answer (see "Disk budget" in `CLAUDE.local.md`)
- Free now: 36.5 GB.
- **Core local simulator ≈ 8–10 GB**: Rust, this repo built, `uv` + Python, `microduck_rl` with its
  Python libraries.
- **Optional extras**: simulated camera (GStreamer, ~1.5–2.5 GB, 58 Homebrew packages) and
  microduck-lab for Mac training experiments (~3 GB).
- **Everything ≈ 13–16 GB**, leaving ~20 GB free.
- Good news found on the way: every Python package the training repo needs has a Mac build (the
  NVIDIA-only ones are skipped on a Mac), so the simulator's body should install here. Not yet run.
