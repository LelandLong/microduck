Hi David, thanks for warp-metal and the Microduck metal branch. I've pre-ordered a Microduck and tried your branch on two Macs, with a Windows/WSL2 RTX 3060 running Pollen's develop as a reference. Results below, plus one install problem with a one-line fix.

1. Install: the locked MuJoCo nightly is gone

uv sync on a fresh clone (71fb768) fails with a 404 for mujoco-3.11.1.dev965888812 from py.mujoco.org. That index now only keeps newer nightlies (≥ 3.12.1), and uv lock --upgrade-package mujoco can't resolve, because mjlab 1.6.0 needs mujoco>=3.11.0,<3.12. Pinning the 3.11.0 release from PyPI works for me:

[tool.uv]
override-dependencies = [
    "mujoco==3.11.0",
    ...
]

After uv lock && uv sync, both Macs show metal:0 and warp_metal.status() → (True, 'active'). I don't know if mujoco_warp@metal-3.11 relied on anything specific to that nightly. Everything below ran on 3.11.0.
