# Leland's Microduck notes

This folder is mine (Leland Long), on the `leland` branch of my fork of
[pollen-robotics/microduck](https://github.com/pollen-robotics/microduck). Nothing here is part of
Pollen's project. I pre-ordered a Microduck in October 2026 and I'm learning the software, the
simulator and reinforcement learning before it arrives.
